# Glossary

Plain meanings, with the everyday picture used in class.

| Term | Meaning | Picture |
| --- | --- | --- |
| Abandoned call | A caller hung up before an agent answered | Leaving the bank queue before reaching the teller |
| AHT | Average handle time: talk, hold and after-call work | Time one customer spends at the counter, paperwork included |
| Batch | Data processed in groups on a schedule | The monthly electricity bill |
| Bronze, silver, gold | Raw, cleaned and ready-for-reports layers (Day 2) | Crude oil, petrol, a finished car |
| CSV | A plain text file where each line is a row and commas split the columns | A spreadsheet you can open in Notepad |
| CTE | A named step inside a query, written with `WITH` | Prepping ingredients before cooking |
| DataFrame | A table in pandas | A spreadsheet you control with code |
| Dictionary | Python data found by name | The contacts app on your phone |
| ETL | Extract, transform, load | Market, kitchen, plate |
| FCR | First contact resolution | A repair that stays fixed |
| Idempotent | Running it twice gives the same result as once | The lift button |
| Index | A lookup structure that speeds up searches | The index at the back of a book |
| Join | Combining rows from two tables using a shared id | Matching a guest list to a seating chart |
| JSONB | A document stored inside a PostgreSQL column | A drawer of loose envelopes in a normal cabinet |
| Lake, warehouse, lakehouse | Raw storage, tidy tables, or both together | Lake water, supermarket shelf, a lake with a filtration plant |
| NaN | How pandas shows an empty or unreadable value | A blank box on a form |
| NoSQL | Databases built for data that is not neat rows and columns | A patient folder instead of a form |
| OLAP | Systems for answering questions about many records | The manager at closing time |
| OLTP | Systems for recording one event at a time | The cashier at the till |
| Primary key | The column that makes each row unique | An employee number |
| Query plan | The route the database chose to answer a query | A GPS route |
| Reject | A row set aside because it failed a rule | A faulty item in the quality-control bin |
| Script | A text file of Python instructions you can run again | A recipe card |
| Service level | Share of calls answered within a target time | Pizzas delivered within the promised 30 minutes |
| Streaming | Data processed continuously as it arrives | The meter on the wall showing power use right now |
| Terminal | A window where you type commands instead of clicking | Ordering at the counter in words |
| Timestamp with time zone | A moment in time that knows which clock it was read on | A flight time printed with the city |
| Transaction | A set of changes that all happen or none do | A bank transfer |
| Upsert | Update the row if it exists, insert it if it does not | Updating a contact instead of adding a second copy |
| UTC | The shared world clock | The one clock everyone agrees to convert to |
| View | A saved query that behaves like a table | A saved search |
| Virtual environment (venv) | A private folder of Python add-ons for one project | A toolbox that stays in your workshop |
| Watermark | A record of the last item processed | A bookmark |
| Window function | A calculation that looks at neighbouring rows without merging them | A leaderboard |
