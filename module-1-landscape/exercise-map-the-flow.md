# Exercise: map your reporting flow

Time: 15 minutes. Groups of four. A whiteboard or a large sheet of paper.

Goal: draw how one number in a report you know reaches the page, and mark which parts you trust.

## Steps

1. Pick one report your team produces. A daily service level report works well.
2. Write the report's name on the far right of the page.
3. Work backwards. Ask "where does this number come from?" and draw a box for each answer. Stop at the system where the event first happened, for example the phone system.
4. Draw an arrow between boxes. On each arrow write how the data moves: a person copies it, a program runs, a scheduled export. Write how often.
5. Colour each box: green if you trust it, amber if it sometimes breaks, red if nobody knows how it works.
6. Repeat steps 2 to 5 for chat, then for fax. Compare the three pictures.

## What you should end up with

Three drawings. They will probably look different, because each channel reaches the report by a different route.

## Discuss

1. Which box would hurt most if it stopped working tomorrow?
2. Where does a person copy data by hand?
3. Which arrow would you most like to replace with something automatic?

Take a photo of your page. The trainer will combine the best parts into one shared map.
